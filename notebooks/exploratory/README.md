# Exploratory Notebooks

Notebook di folder ini mendokumentasikan eksperimen tambahan sebelum protocol
freeze, termasuk attention dan variasi backbone/tuning. Eksperimen tersebut
tidak menjadi kandidat atau bukti utama dalam Protocol v1.0.0.

Notebook boleh dirujuk sebagai riwayat eksplorasi apabila diberi label
*exploratory*. Angka, checkpoint, dan kesimpulannya tidak boleh dicampur dengan
hasil C1–C7 canonical atau digunakan untuk melakukan model chasing.
