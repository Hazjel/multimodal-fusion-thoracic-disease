# Pre-Protocol Notebook Archive

Notebook di folder ini dibuat sebelum Canonical Execution Protocol v1.0.0
dibekukan. File dipertahankan bersama output historisnya untuk audit jejak
pengembangan, bukan sebagai implementation path atau bukti canonical.

Beberapa notebook menggunakan split, checkpoint, CheXNet assumptions, atau
protokol XAI lama. Karena itu:

- jangan menjalankan ulang notebook ini untuk menghasilkan angka BAB IV;
- jangan menyalin hasilnya ke tabel canonical;
- jangan menggunakan checkpoint yang dirujuk untuk melanjutkan C3–C7;
- official-test output di dalamnya tetap dianggap memiliki prior exposure.

Evidence canonical berada di `results/canonical/<protocol_hash>/` dan dibuat
melalui `run_experiment.py`.
